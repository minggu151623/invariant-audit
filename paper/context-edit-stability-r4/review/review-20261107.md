## Findings

No mathematical error was found. One statement-level defect was found and is
now fixed.

### Theorem 1 and Corollary 1 lacked their scope

Both were stated "for every table". They hold only for an initially rejected
target.

Counterexample for accepted targets: one rule x→y, target (0,0), one context
row (1,1).
- The target is accepted.
- With editable keys, one key edit makes it reject, so rho_full = 1.
- With fixed keys, the target's group stays {t}, so rho_fixed = ∞ (Theorem 3).
- This happens even though the family is laminar, so the stated corollary
  fails for accepted targets.

The fix:
- Theorem 1, Corollary 1 and contributions 1–2 now say "initially rejected
  target".
- Section 3 opens with a sentence fixing the scope.
- The counterexample is added after Corollary 1.

### Steps re-derived

- **Lemma 1.** Both cases were checked: cost does not increase, and no
  contribution decreases.
- **Theorem 1.**
  - Suppose an affected margin of L stays below 1 after a step. Then its group
    still has a context row with nonzero y, so its chain gets a flip.
  - Because the margin was below 1 before the step, the invariant gives
    m_L ≥ m_H. L then gains at least 1, as much as H, so the invariant
    persists.
  - Each flipped row starts with nonzero y, so it is flipped at most once and
    is disjoint from the R edited rows.
  - Hence the cost is at most R + Σ w_j K_j.
- **Theorem 2.**
  - Each critical group is {t, r_i}: the antichain property excludes r_l
    (l ≠ i), the missing key j excludes p, and the choice of C excludes the
    support rows.
  - The other checks accept, using w support rows or the absence of any
    rival.
  - p_j → 0 gives rho_full = 1. The w distinct cells r_i.y are forced, so
    rho_fixed = w. For d > 2, moving r_i.y to a third value still ties.
- **Corollary 1.** w = 1 if and only if every F_j is a chain, which holds if
  and only if F is laminar.
- **Theorem 3.**
  - Lower bound: a y edit changes a margin by at most 2, a key edit by at
    most 1.
  - The attaining edits exist because a_X ≥ 2 whenever an accepted group is
    nonsingleton.
  - The singleton case was checked separately.
- **Theorem 4.**
  - Each edit yields at most one chosen set.
  - A column with no key edit keeps its group. With binary y, at least one
    set row of that group must end at 0.
- **Proposition 1.** Both instances were recomputed.

## Randomized brute force (post hoc review aid, not preregistered)

`review_bruteforce.py` was written separately from the project code
(standard library only). It enumerates raw cell edits with increasing cost
and uses 3 keys, with ternary keys and ternary y. This lies outside the E013
grids, which covered binary keys up to q = 3, ternary y up to 2 rows, and
ternary keys only at q = 2.

For rejected targets it checks:
- 1 ≤ rho_full ≤ rho_fixed ≤ w · rho_full;
- equality for laminar families.

For accepted targets it checks the Theorem 3 formula for both edit models.

The runs are in `review_bruteforce-output.txt`: 10,900 random tables with 4–6
context rows, including 130 strict gaps. All checks passed. Random sampling
can miss rare cases.
