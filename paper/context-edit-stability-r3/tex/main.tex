\begin{abstract}
A plurality-based functional-dependency check judges a target value using rows
that match its determinant values. When determinant cells can change, group
membership changes as well. We study the minimum number of context-cell edits
that reverses a fixed target's decision, protecting its entire row. For checks
with a common dependent attribute and independent unit-cost categorical edits,
we prove a row-action dominance reduction for making a rejected target accept.
That decision problem is NP-complete when the schema varies, already for binary
domains and singleton determinants, with keys either fixed or editable.
For the opposite direction, we derive an exact formula: nonsingleton groups
retain their ordinary vote-margin cost, and only singleton groups can make
editable keys strictly reduce the global radius. Exhaustive finite checks and a
bounded optimization comparison support the implementations. A reused-source
study covers 18,734 target cells from Beers, Flights and Rayyan. Among 13,762
accepted targets, 1,133 fixed-key infinite radii become finite and one finite
radius decreases. No strict reduction appears in 30 exact rejected-target
pairs; two full models time out. Stability does not establish correctness:
1,493 accepted targets disagree with references despite radius at least two.
\end{abstract}

\section{Introduction}
Functional dependencies (FDs) describe agreement constraints between attributes.
In an imperfect table, a simple detector can compare an observed dependent
value with the unique plurality among rows sharing its determinant values.
Such a decision depends on context: changing another row's key can move that
row into or out of the target's group. A certificate that protects all keys
therefore answers a different question from one allowing key errors.

We study this distinction as an exact decision-sensitivity problem. The target
value is not corrected, the target row is immutable, and the edited table need
not satisfy all FDs. We count changed cells in other rows, rather than insertions,
deletions, changed records, or changes to an output label. A radius certifies
stability under its stated edit model; it does not certify factual validity.

Our technical results concern several checks sharing one dependent attribute.
First, a componentwise dominance lemma reduces accepting counterfactuals to
at most $2^q+1$ actions per context row, where $q$ is the number of key columns.
Second, an exact rejection formula identifies a singleton bottleneck: keys
strictly lower an accepted target's radius exactly when a singleton group's
cheapest rival import costs less than every nonsingleton group's margin cost.
Third, making a rejected target accept within a cell-edit budget is
NP-complete even with binary values and singleton determinants, when the
schema varies. The same hardness construction works with fixed or editable
keys. Together these results explain different algorithms for the two
decision directions; key mutability is not itself the source of hardness.

Minimum interventions, predicate-equivalent domains, voting margins and integer
optimization are established ingredients; we do not claim them as inventions.
The contribution presented here is the specialized dominance and singleton
characterization and an explicit directional-complexity result under stated
assumptions, with bounded computational and source-table evidence.
In particular, our source results do not show a general
accepting-direction advantage from mutable keys.


The intended use is an edit-budget sensitivity audit, not a repair prescription.
For a declared context-edit budget $B$, a radius greater than $B$ certifies that
the present decision survives every permitted edit within that budget; a radius
at most $B$ supplies an explicit counterexample to that certificate. This lets
an auditor distinguish trusting determinant cells from allowing them to be
wrong. It does not establish which cells are actually wrong, or validate the
choice of budget and unit costs. We position the result as a restricted
theory/algorithm note, rather than an accuracy-improving cleaning system.

\section{Model and edit semantics}
Let $T=(t,r_1,\ldots,r_{n-1})$ be identified rows with $q\geq1$ categorical key
attributes and one dependent attribute $y$. The finite RHS domain has
$d\geq2$ values. Each key domain contains the target value and an alternative.
By independently relabeling column values, assume $t=(0,\ldots,0)$.
Rules have nonempty determinants $X_g\subseteq\{1,\ldots,q\}$, $g=1,\ldots,m$,
and common RHS $y\notin X_g$. Define
\[
 G_g(T)=\{r\in T:r[X_g]=t[X_g]\},\qquad
 c_{gv}(T)=|\{r\in G_g(T):r_y=v\}|.
\]
The detector accepts the target iff
\begin{equation}\label{eq:accept}
 D(T,t)=1\quad\Longleftrightarrow\quad
 c_{g0}(T)>c_{gv}(T)\quad\text{for all }g,\ v\ne0.
\end{equation}
Ties reject. Unique plurality does not require an absolute majority when $d>2$.

An edited table $T'$ has the same identified rows, and $t$ is unchanged in every
column. Context cells may independently take any value of their column's
domain. The cost is cell Hamming distance
\[
 H(T,T')=\sum_{i=1}^{n-1}\sum_{j=1}^{q+1}\ind[r_{ij}\ne r'_{ij}].
\]
Let $\rho_{\rm full}$ minimize this cost subject to $D(T',t)\ne D(T,t)$.
Let $\rho_{\rm fixed}$ impose the additional restriction that all key cells
remain unchanged. An impossible flip has radius $\INF$. Every integer budget
$k<\rho$ preserves the initial decision. At cost $\rho<\INF$, a witness flips it.

There are no additional validity constraints, NULL semantics, insertion/deletion,
unequal edit costs, or requirements to preserve other targets' decisions. These
restrictions are essential to the results below.

\section{Making an accepted target reject}
Assume $D(T,t)=1$. Write $a_g=c_{g0}(T)$ and
$b_g=\max_{v\ne0}c_{gv}(T)$, allowing absent values with count zero.
For a context row $r$, let
$h_g(r)=|\{j\in X_g:r_j\ne0\}|$.

\begin{theorem}[Exact rejection radius]\label{thm:reject}
Define
\[
 C_g=\begin{cases}
 \left\lceil(a_g-b_g)/2\right\rceil,& |G_g(T)|\geq2,\\[3pt]
 \displaystyle\min_{r\ne t}\bigl(h_g(r)+\ind[r_y=0]\bigr),&G_g(T)=\{t\},
 \end{cases}
\]
where an empty minimum is $\INF$. Then
$\rho_{\rm full}=\min_g C_g$.
\end{theorem}
\begin{proof}
For a nonsingleton group, fix a rival $v$. A key-cell edit changes its target/rival
margin by at most one: only one row can enter or leave this group. An RHS-cell
edit changes it by at most two. These bounds hold at any intermediate table.
A final Hamming edit can be implemented by changing each differing cell once.
Rejection therefore costs at least $\lceil(a_g-b_g)/2\rceil$.

Choose a strongest rival and change that many context RHS-0 cells in the group
to it, keeping keys fixed. Each edit reduces the selected margin by two, reaching
a tie or loss. There are enough editable zero cells: initial acceptance and a
nonsingleton group imply $a_g\geq2$, and
$\lceil(a_g-b_g)/2\rceil\leq\lceil a_g/2\rceil\leq a_g-1$.

For a singleton group, a rejecting destination must contain at least one
nonzero context RHS in the target group. That row must change its $h_g(r)$
initially nonmatching keys and also its RHS if originally zero. This lower
bound is attained by editing just that row; it then ties the protected target
one-to-one. If there is no context row, no flip is possible.

Finally, global rejection is a disjunction of rule rejections. Any flip rejects
at least one rule; a minimum-cost witness for any one rule already suffices.
Taking the minimum over rules proves the result without an independence
assumption about their overlapping groups.
\end{proof}

\begin{corollary}[Exact condition for keys to help]\label{cor:singleton}
Let $A$ be the minimum nonsingleton margin cost and $S$ the minimum singleton
import cost, using $\INF$ for an absent kind. Then
\[
 \rho_{\rm fixed}=A,\qquad \rho_{\rm full}=\min(A,S).
\]
Thus keys strictly reduce the radius iff $S<A$. A singleton group is necessary,
but not sufficient. With no singleton target groups, the radii are equal.
\end{corollary}

A scan obtains group counts and best singleton imports. After choosing the
cheapest rule, it materializes only one witness. For fixed schema and alphabet,
this is linear in $n$; the implementation also scans the RHS alphabet when
choosing a rival. The condition is not a claim that singleton values are wrong.
For example, with target $(0,0,0,0)$, context $(0,1,1,0)$, and rules
$a\to y,b\to y$, a singleton exists but $A=1<S=2$, so both radii are one.


\section{Decision distance versus whole-table repair}
For comparison within our identified-row model, let $R(T)$ be the minimum
context-cell cost making the entire edited table satisfy every FD as an
agreement constraint, still protecting $t$. This comparison protects the same
target in both objectives; it is not a redefinition of prior repair semantics.
\begin{proposition}[No constant-factor substitution]\label{prop:separation}
Even with one rule $x\to y$ and binary $y$, the ratios
$\rho_{\rm full}/R(T)$ and $R(T)/\rho_{\rm full}$ can each be arbitrarily large
on instances where both costs are positive and finite.
\end{proposition}
\begin{proof}
For any $h\geq1$, use target $(0,0)$, $2h$ additional $(0,0)$ rows and one
$(0,1)$ row, with binary domains. Changing the lone one to zero repairs the
table; since it initially violates the FD, $R(T)=1$.
Theorem~\ref{thm:reject} gives $\rho_{\rm full}=h$ from counts $2h+1$ and one.
Thus the first ratio is $h$.

For any $k\geq1$, use target $(0,0)$ and pairs $(i,0),(i,1)$ for
$i=1,\ldots,k$, with key domain $\{0,\ldots,k\}$.
Each original conflicting pair requires an edit in one of its own cells;
otherwise that pair still violates the FD. The disjoint pairs require at
least $k$ edits, and changing each pair's one to zero attains $R(T)=k$.
The target's group is initially singleton. Changing the key of $(1,1)$ to
zero creates a tie with one edit, so $\rho_{\rm full}=1$.
The second ratio is $k$.
\end{proof}
These elementary families clarify the objective, rather than serve as another
priority claim. A whole-table repair optimum cannot simply be reported as this
decision radius. They do not exclude reductions between computational problems
or the use of general repair/constraint machinery with a different encoding.
For $h,k\in\{1,2,3\}$, unrestricted raw-destination enumeration checks both
costs; together with the coupled example in both edit models, eight checks
cover 285,032 destinations. These small illustrative checks are separate from
the E008--E011 studies and are not additional source validation.

\section{Making a rejected target accept}
For row $r$ define the match mask $M(r)=\{j:r_j=0\}$ and contribution
\[
 A_{gv}(r)=\ind[X_g\subseteq M(r)]
           \bigl(\ind[r_y=0]-\ind[r_y=v]\bigr).
\]
Since the target contributes one, acceptance means
$1+\sum_{r\ne t}A_{gv}(r)\geq1$ for all $g,v\ne0$.
Other nonmatching key values can retain their original identities; changing a
matching key to nonmatching uses one allowed alternative. A prescribed mask
change therefore costs its symmetric-difference size. This predicate quotient
is setup rather than a claimed new generic reduction.

\begin{lemma}[Canonical accepting actions]\label{lem:dominance}
For every original row $r$ and arbitrary destination $u$, there is a row $c$
with $H(r,c)\leq H(r,u)$ and $A_{gv}(c)\geq A_{gv}(u)$ for every rule and rival.
It belongs to the following action set, writing $M_0=M(r)$:
\begin{enumerate}
\item if $r_y=0$: RHS 0 with any supermask of $M_0$;
\item if $r_y\ne0$: unchanged RHS with any submask of $M_0$, or RHS 0 with any
supermask of $M_0$.
\end{enumerate}
\end{lemma}
\begin{proof}
Write $M_*=M(u)$. If $r_y=0$, choose RHS 0 and mask $M_0\cup M_*$.
Restoring originally matching keys and retaining the original RHS cannot
increase cost. Every group containing $u$ also contains $c$; its contribution
is positive instead of zero or negative, and no new negative contribution arises.

If $r_y\ne0$ and $u_y=r_y$, retain that RHS and choose $M_0\cap M_*$.
Restoring originally nonmatching keys removes edits. Group membership can only
shrink relative to $u$, removing negative contributions and losing no positive
one. If instead $u_y\ne r_y$, choose RHS 0 and $M_0\cup M_*$.
Both destinations use one RHS edit. The chosen keys cost no more; expanding
positive membership or replacing negative contributions cannot lower a margin.
Concrete key values are reconstructed without gratuitous changes between
different nonmatching values, so these abstract costs are attainable cell costs.
\end{proof}

\begin{theorem}[Exact reduced accepting optimization]\label{thm:accepting}
The minimum accepting cost over the canonical actions equals the minimum over
all permitted raw cell edits. Each row needs at most $2^q+1$ actions.
\end{theorem}
\begin{proof}
Apply Lemma~\ref{lem:dominance} to every row of an arbitrary accepting witness.
All margins weakly increase and cost weakly decreases, so the resulting
canonical table still accepts. Conversely, canonical edits are allowed raw
edits. If $p=|M_0|$, an original-zero row has $2^{q-p}$ actions; an original
nonzero row has $2^p+2^{q-p}\leq2^q+1$ actions.
\end{proof}

For action $a$ of row $i$, use binary $z_{ia}$ with raw cost $w_{ia}$ and
contribution $A_{gv}(i,a)$. An exact mixed-integer formulation is
\begin{align*}
 \min\ &\sum_{i,a}w_{ia}z_{ia},\\
 \text{s.t. }&\sum_a z_{ia}=1\quad\text{for every context row }i,\\
 &\sum_{i,a}A_{gv}(i,a)z_{ia}\geq0\quad\text{for every }g,v\ne0.
\end{align*}
For fixed keys, restrict each mask to its original value. Rivals absent from a
group initially can be omitted in the accepting model: retaining a nonzero RHS
only loses matches, while every RHS change goes to zero. Such a rival cannot
enter the group, and the protected target ensures a positive target count.
This pruning is invalid for rejection, where introducing an absent rival may
create a tie.

The reduction is independent of key-domain cardinality, but enumeration remains
exponential in $q$, and the number of rival margins depends on $m(d-1)$.
Neither exactness nor a smaller formulation guarantees a rapid solve.

\section{Accepting complexity with a varying schema}
Consider the decision problem of accepting an initially rejected target within
a given nonnegative integer budget $B$. The table and rules are explicit input.
\begin{theorem}[Binary singleton acceptance is NP-complete]\label{thm:hardness}
The accepting decision problem is NP-complete in combined complexity, even
when every column is binary, every determinant is a singleton, and every target
group is initially tied. This holds both with fixed keys and with editable keys.
\end{theorem}
\begin{proof}
Reduce from Set Cover~\cite{karp}. Let the nonempty universe be
$U=\{1,\ldots,q\}$ and the input sets $S_1,\ldots,S_\ell$ cover $U$.
Write $c_g=|\{i:g\in S_i\}|\geq1$ and let $\tau$ be the minimum cover size.
Use binary keys $x_1,\ldots,x_q$, binary RHS $y$, rules $x_g\to y$, and an
immutable all-zero target. For each $S_i$ add one set row with RHS 1 and
$x_g=0$ exactly when $g\in S_i$. For each $g$, add $c_g-1$ support rows with
RHS 0, key $x_g=0$, and every other key 1. Rows remain individually identified.
There are $\ell+\sum_g(c_g-1)$ context rows, so the construction is polynomial.
Each target group has $c_g$ zeros (including the target) and $c_g$ ones.

Given a cover, flip the corresponding set-row RHS cells to zero. Each group
gains at least two in its zero-minus-one margin and accepts. This costs the
cover size with fixed or editable keys, hence both optima are at most $\tau$.

Conversely, take any accepting edited table of Hamming cost $K$. For every
changed key cell in column $x_g$, select an arbitrary original input set
containing $g$. For every original set row whose final RHS is zero, select
its input set. Before discarding repeated selections, each is charged to a
distinct changed key or set-row RHS cell, so at most $K$ sets are selected.
Fix any element $g$. If column $x_g$ contains a key edit, the first selection
rule covers $g$. Otherwise its target-group membership is unchanged, since
its determinant is just $x_g$. Starting from a tie, a positive final margin
requires at least one original RHS-1 group member to flip to zero: flipping
an original zero to one only hurts. Such a member is a set row containing $g$,
which the second selection rule selects. Thus the selected sets cover all of
$U$, proving $\tau\leq K$. This includes mixed key/RHS edits and support-row
edits, without a canonical-action assumption.

Both optima therefore equal $\tau$, and we preserve the budget $B$.
Restricting Set Cover to coverable nonempty universes retains hardness;
trivial empty or uncovered cases can be decided separately. Finally, a
destination table is a polynomial-size certificate, whose Hamming cost,
protected row, edit restrictions and group counts can be checked in polynomial
time. This gives NP membership for both versions.
\end{proof}

The hardness concerns a growing number of keys and rules, not fixed-schema
data complexity. With fixed $q$ and fixed RHS alphabet size $d$, a standard
dynamic program over the $m(d-1)$ accumulated margin contributions is
polynomial: retain the least cost for each vector after each row, using the
canonical actions. Duplicate rules can be removed, giving $m\leq2^q-1$;
each coordinate lies in $[-n,n]$. At the end, require every coordinate to be
nonnegative, accounting for the protected target's contribution of one.
This gives at most $O(n(2n+1)^{m(d-1)}(2^q+1)m(d-1))$ transition work.
It is an elementary tractability observation, not a practical solver or an
FPT claim. The reduction above shows no full-key cost advantage: both radii
equal the cover optimum. Its purpose is the worst-case directional distinction
from Theorem~\ref{thm:reject}, not a claim of empirical difficulty or accuracy.

E012 separately checks the reduction on every coverable multiset of one to
three subsets of universes of size one to three, including empty and repeated
subsets: 111 instances. Raw binary cell-subset enumeration through budget $q$
checks 222 radii and 147,523 destinations across both edit models. All optima
match independent input-set enumeration. Reverse extraction succeeds on all
25,490 accepting destinations, including 24,288 with key edits. Counts across
models overlap. These finite checks test the construction and extraction, not
the universal proof, the unimplemented DP observation or historical priority.

\section{Related work and scope}
Cell-level repair and intervention objectives substantially predate this work.
Debosschere and Geerts~\cite{cellcauses}, Section 2, define cell modifications,
their cardinality distance and repairs satisfying the FD set. Their
Propositions 1--3 concern responsibility complexity and repair/cause
correspondence. Our edited table may violate FDs: the goal is a protected
target's plurality-decision flip, not consistency restoration.
Proposition~\ref{prop:separation} makes the numerical distinction explicit.
Bertossi~\cite{bertossi}, Sections 3.1 and 4, gives abstract repair semantics
and an attribute-cause instantiation using NULL replacements. We instead allow
arbitrary domain values, do not assign causal responsibility to a particular
cell, and need not preserve other outputs.

Meliou et al.~\cite{vcc}, Sections 4.1--4.4 and Theorems 14, 15 and 17,
give predicate partitions, cause/responsibility equivalence and SAT-based
reasoning about changed inputs. General vote operations already optimize
constructive/destructive goals with score constraints~\cite{xia},
Definitions 2--3 and Section 4. Those generic frameworks motivate an encoding;
they are not claimed as new here. Our accepting proof additionally constructs
a no-more-expensive row destination dominating every relevant margin, and our
rejection proof constructs a witness attaining the margin/import lower bound.
These are the specialized statements being presented; their absence from the
inspected theorem statements is not a systematic originality certificate.

Set Cover incidence matrices and balancing constructions are established in
multi-referendum lobbying~\cite{lobbying}, Sections 2--3, Reductions 1--2.
There, an action modifies a voter row; here the cost is per cell and a key
edit changes group membership. Theorem~\ref{thm:hardness} credits that covering
technique and supplies the additional lower-bound argument for arbitrary key
edits. We claim neither a new general hardness technique nor an originality
certificate from this targeted comparison.

FD repairs with immutable trusted cells are established~\cite{repairs}.
Certified k-NN over FD repairs~\cite{knn} uses different possible worlds and
edit semantics. Recent work distinguishes AFD strength from detection
utility~\cite{wan}; our radius likewise must not be interpreted as accuracy.
The practical evidence here concerns sensitivity and bounded computation,
not a demonstrated improvement to a deployed auditing workflow.

The same-RHS restriction permits a single change to zero to improve all
relevant margins. Different dependents, weighted costs, additional constraints
or mutable targets can invalidate the proofs. Empty-as-category source semantics
are deliberate, and reference labels may themselves be imperfect. Source reuse,
small synthetic sizes, sparse rejected sampling, two solver timeouts and the
lack of independent scientific assessment limit the empirical conclusions.

source manifests,
all outcomes, witnesses and separate delivery checks. Its manuscript snapshot
predates this revision. A separate R2 supplement provides the raw enumerator
and all records for the new analytical examples, the comparison notes and
revision verification. The original source CSV cache was unavailable at this
revision; no new raw-source reconstruction or solver/timing run is claimed.
The R3 supplement adds the E012 protocol, raw-cell enumerator, full case records,
proof and complexity comparison. Its protocol/implementation commits are
\texttt{9f14171}/\texttt{65ad518}; execution used Python 3.14.5 with only the
standard library. Earlier evidence and the R2 packet are preserved unchanged.
No public code URL or
arXiv submission is claimed in this working draft. E008 protocol/implementation
commits are \texttt{efc1365}/\texttt{14fe214}; E009 uses
\texttt{96962be}/\texttt{05a2b07}; E010 uses
\texttt{fbd04cb}/\texttt{2212b58}; E011 uses
\texttt{86dad7d}/\texttt{fd341d4}. The exact environment for E009--E011 is
Python 3.13.5, NumPy 2.1.3 and SciPy 1.17.1 on an arm64 Mac.
Solver-optimal results require a checked integer-feasible witness, objective
agreement and bound/gap checks within $10^{-7}$. Time-limit outcomes stay censored.

E011's separate checker uses original categorical codes, direct formulas and
incremental group-count updates, rechecking 26,453 finite source witnesses,
selection hashes, reference labels and stage hashes. Such separate code is
self-review in one research environment, not independent human verification.
Source cell strings remain outside the outputs; witnesses contain original
row/column coordinates and target-relative destination codes. Exact radius
histograms and reference buckets are retained, including all negative outcomes.
Generative AI was used substantially for ideation, proofs, code and writing.
The named human author's substantive review is pending; this draft is not
authorization to submit or publish it.

\section{Conclusion}
Editable keys have a precisely characterized effect on accepted-target
stability: only singleton groups can improve on the fixed-key rejection cost.
For accepting counterfactuals, canonical row dominance preserves exact optima
while reducing raw categorical choices. A Set Cover reduction proves
NP-completeness already for binary singleton checks with a varying schema,
including fixed keys. The implementations have finite
validation and bounded computational value, but reused-source evidence is
concentrated in fixed-infinite transitions and does not show a rejected-subset
cost gain. Reporting these limits keeps decision stability distinct from
correctness and the specialized result distinct from generic intervention ideas.
